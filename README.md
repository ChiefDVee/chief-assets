# Chief Assets
Publieke asset repository voor gebruik door externe tools (Claude, Canva, etc.)

## Structuur
- images/profiles/ — profielfoto's
- images/banners/  — bannerafbeeldingen
- images/logos/    — logo's
- images/misc/     — overige afbeeldingen

## Gebruik
Raw URL formaat:
https://raw.githubusercontent.com/ChiefDVee/chief-assets/main/images/[map]/[bestand]

Voorbeeld:
