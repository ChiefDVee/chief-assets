# Fonts

## bodoni-moda/
Bodoni Moda (Indestructible Type), SIL Open Font License 1.1 — see `bodoni-moda/OFL.txt`.
Latin subset, woff2, weights 400 + 700 (via Fontsource 5.1.0). Web embedding and redistribution allowed under the OFL.

Used by chiefke.com/qotd (CHIEF'S QOTD archive) as the open-licensed stand-in for Didot, which is an Apple
system font and may not be embedded on the web.

URL (jsDelivr, correct MIME + CORS):
https://cdn.jsdelivr.net/gh/ChiefDVee/chief-assets@main/fonts/bodoni-moda/bodoni-moda-latin-700-normal.woff2

Since 2026-11-11 chiefke.com/qotd no longer loads Bodoni Moda via jsDelivr: the hub self-hosts a copy of these files
in `14_CHIEFHUB/assets/fonts/` (`bodoni-moda-latin-{400,700}-normal.woff2` + `OFL-bodonimoda.txt`, declared in
`fonts.css` as "QOTD Bodoni"). This folder stays the source; after a font update, copy the files there again.
