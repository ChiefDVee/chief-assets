# Fonts

## bodoni-moda/
Bodoni Moda (Indestructible Type), SIL Open Font License 1.1 — see `bodoni-moda/OFL.txt`.
Latin subset, woff2, weights 400 + 700 (via Fontsource 5.1.0). Web embedding and redistribution allowed under the OFL.

Used by chiefke.com/qotd (CHIEF'S QOTD archive) as the open-licensed stand-in for Didot, which is an Apple
system font and may not be embedded on the web.
